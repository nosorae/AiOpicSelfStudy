# 0032. 분석 작업 상태는 DB 한 곳에 두고 플랫폼 대기열은 비우기만 한다

- 상태: 채택
- 날짜: 2026-10-11

## 배경

답변 분석과 회차 등급을 보낼 일은 플랫폼 대기열(Android WorkManager, iOS NSUserDefaults 목록)에, 결과는 Room 의 답변과 회차에 따로 있었다. 둘이 어긋나면 리포트가 끝없이 "분석 대기 중"에 머물렀다. 앱이 보내는 중에 죽거나, 대기열이 다시 보내기를 다 써 작업을 버리거나, Gemini 가 답하지 않는 경우다. 받은 응답을 해석하다 실패하면 토큰을 쓴 응답도 사라져 다시 불러야 했다.

## 후보

1. 플랫폼 대기열을 그대로 두고 앱을 켤 때 어긋난 답변을 다시 넣는다(#203 의 방식): 켜기 전까지는 어긋난 채로 보인다
2. 작업 상태를 Room 의 작업 표 한 줄로 두고, 플랫폼 대기열은 "표를 비워라"는 신호만 준다
3. 작업 상태를 답변과 회차 JSON 안에 넣는다: 화면은 한 곳만 보지만 재시도 시각처럼 화면과 상관없는 값이 모델에 섞이고, 시각으로 찾는 쿼리를 쓸 수 없다

## 결정

후보 2를 고른다.

- 작업 하나는 `analysis_job` 한 줄(종류, 대상 id, 상태, 시도 횟수, 다음 시도 시각, 실패 이유, 갱신 시각)이다. 상태는 대기, 진행 중, 연결 기다림, 다시 보낼 예정, 성공, 실패다
- `AnalysisJobs` 만 이 표를 쓴다. 넣기, 비우기, 앱을 켤 때 되돌리기, 다시 분석하기, 동의 철회 취소가 모두 여기 있다
- 비우기는 한 번에 하나씩, 넣은 순서로 보낸다. 무료 키의 분당 한도 때문이다
- Gemini 호출 하나는 2분 안에 끝나야 한다. 넘으면 다시 보낼 실패로 센다
- 다시 보낼 실패(429, 408, 5xx, 시간 초과)는 30초부터 두 배씩 기다려 3번까지 다시 보내고, 다 쓰면 실패로 끝낸다. 연결 오류는 횟수를 쓰지 않고 연결을 기다린다
- 앱을 켜면 진행 중으로 남은 작업을 대기로 돌리고, 작업 없이 기다림인 답변을 대기로 넣는다
- 받은 응답 원문은 해석하기 전에 `analysis_response` 에 단계마다 저장한다. 같은 작업을 다시 돌리면 원문을 다시 해석하고 Gemini 를 부르지 않는다. 포트 시그니처를 바꾸지 않으려고 원문 저장소는 코루틴 문맥(`SavedResponses`)으로 넘긴다
- Android 는 WorkManager 고유 작업 사슬 하나(연결 조건)가 비우기를 부른다. iOS 는 앱이 앞에 있고 연결돼 있을 때 비우고, 뒤로 가면 BGProcessingTask(연결 필요)를 예약한다. NSUserDefaults 대기열은 없앤다
- 리포트 두 화면은 작업 표를 구독해 무엇을 기다리는지(차례, 보내는 중, 연결 기다림, 다시 보낼 때까지 남은 초) 보인다

## 이유

- 상태가 한 곳에만 있으면 어긋날 일이 없다. 화면, 비우기, 되돌리기가 같은 줄을 읽는다
- 작업과 답변을 같은 DB 에 둬서 "작업은 성공인데 답변은 기다림" 같은 경우를 앱을 켤 때 한 번에 찾는다
- 플랫폼 대기열에 상태가 없으면 두 플랫폼의 재시도 규칙 차이(WorkManager 백오프, iOS 백그라운드 시간)가 결과에 섞이지 않는다. 재시도 규칙은 공통 코드 하나이고 테스트 시계로 확인한다
- 응답을 먼저 저장하면 해석 코드의 버그나 앱 종료로 사용자의 하루 한도(모델마다 20번)를 다시 쓰지 않는다

## 결과

- DB version 이 1에서 2가 된다. 이전은 표 두 개를 더하는 SQL 하나다(`OPIC_MIGRATIONS`). 옛 버전에서 쌓인 기다림 답변은 이전 뒤 첫 실행의 되돌리기가 작업으로 옮긴다
- 연결 오류는 실패로 끝나지 않는다. 기기는 연결됐는데 Gemini 연결만 계속 끊기면(TLS 오류 등) 30초마다 다시 보내며 기다린다. 이런 경우가 보이면 연결 오류에도 넉넉한 횟수를 둔다
- 저장한 원문은 지우지 않는다. 답변 하나에 수 KB 다. 쌓인 양이 문제가 되면 성공한 작업의 원문을 지운다
- 다시 분석하기는 저장한 원문이 있으면 다시 해석만 한다. 원문 자체가 틀렸으면 출력 검사(F5.4)가 같은 실행에서 한 번 새로 받는다
