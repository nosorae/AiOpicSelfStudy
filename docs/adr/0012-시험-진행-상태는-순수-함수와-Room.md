# 0012. 시험 진행은 순수 함수가 계산하고 Room 이 진실 공급원

- 상태: 채택
- 날짜: 2026-10-09

## 배경

모의시험은 앱을 껐다 켜도 멈춘 문항에서 이어져야 한다. 7번 뒤 재조정, 40분 끝, 앱 종료가 겹치는 경우가 많다.

## 후보

1. 화면(ViewModel)이 상태를 들고 있다가 저장한다
2. 일어난 일을 모두 기록하고 켤 때 다시 계산한다
3. 순수 함수 하나가 다음 상태를 계산하고, 바뀔 때마다 통째로 Room 에 저장한다

## 결정

engine 의 순수 함수 하나가 (지금 상태, 일어난 일)을 받아 다음 상태를 돌려준다. 저장, 화면 일은 하지 않는다. 바뀐 상태는 통째로 Room 에 저장하고, 화면은 Room 의 상태를 구독해 그린다.

## 이유

"7번에서 껐다 켜면 재조정 화면부터" 같은 경우를 기기 없이 단위 테스트로 모두 확인한다. 화면이 상태를 들고 있으면 앱이 갑자기 죽을 때 저장 시점을 놓친다. 일어난 일을 모두 기록하는 방식은 시험 한 회짜리 앱에 비해 크다.

## 결과

상태가 바뀔 때마다 DB 쓰기가 일어난다. 상태는 작아서 비용이 작다. 시간은 실행 중엔 단조 시계로 재고 조각이 끝날 때마다 누적 시간을 더한다.
