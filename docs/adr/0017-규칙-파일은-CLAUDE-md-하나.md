# 0017. 규칙 파일은 CLAUDE.md 하나

- 상태: 대체됨(0025)
- 날짜: 2026-10-09

## 배경

모듈 구조, 명령, 작업 규칙이 `AGENTS.md` 에 있고 `CLAUDE.md` 가 그 파일을 불러와 Claude Code 메모를 덧붙였다. 규칙을 고칠 때 어느 파일에 넣을지 매번 정해야 했고, 두 파일에 같은 내용이 나뉘어 들어갈 수 있었다.

## 후보

1. `AGENTS.md` 에 공통 규칙, `CLAUDE.md` 에 Claude Code 메모를 두는 지금 구성을 유지한다
2. 모든 규칙을 `CLAUDE.md` 하나에 두고 `AGENTS.md` 를 지운다

## 결정

규칙 파일은 `CLAUDE.md` 하나다. 모듈 구조, 명령, 작업 규칙, Claude Code 메모를 모두 여기에 쓴다. 저장소 안의 문서와 스킬은 `CLAUDE.md` 를 가리킨다.

## 이유

이 저장소의 코드와 문서는 Claude Code 로만 만든다. 다른 도구가 읽을 파일이 없으니 둘로 나눌 이유가 없다. 파일이 하나면 규칙을 넣을 곳을 고민하지 않고, 두 파일 사이에서 내용이 어긋날 일도 없다.

## 결과

Claude Code 가 아닌 에이전트 도구를 쓰게 되면 그때 공통 규칙을 별도 파일로 나누고 이 결정을 새 ADR 로 바꾼다.
