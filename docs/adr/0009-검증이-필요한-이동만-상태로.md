# 0009. 저장이나 검증이 필요한 이동만 상태로 한다

- 상태: 채택
- 날짜: 2026-10-09

## 배경

화면 이동을 ViewModel 이 정할지 화면이 바로 할지 정해야 한다.

## 후보

1. 모든 이동을 UiState `navigation` 필드로
2. 저장, 검증이 끝나야 가는 이동만 상태로, 나머지는 화면이 바로

## 결정

시험 나가기(저장 후), 시험 끝, 키 확인 성공처럼 저장이나 검증이 끝나야 가는 이동만 UiState `navigation` 필드로 한다. 뒤로가기, 탭 전환, 리포트 열기는 화면이 람다로 바로 처리한다. 막아야 하는 뒤로가기(시험 중)만 가로챈다.

## 이유

모든 이동을 상태로 하면 단순 이동마다 Intent 와 처리 완료 Intent 쌍이 늘어난다. 시스템 뒤로가기를 상태로 돌리면 예측 뒤로가기 애니메이션이 끊긴다. ViewModel 이 판단해야 하는 이동만 ViewModel 에 둔다.

## 결과

이동이 두 곳(ViewModel 상태, 화면 람다)에서 일어난다. 기준은 "이동 전에 ViewModel 이 끝내야 할 일이 있나" 하나다.
