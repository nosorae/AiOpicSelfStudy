# 0014. 음성 전송 동의를 두 플랫폼 모두에서 받는다

- 상태: 채택
- 날짜: 2026-10-09

## 배경

녹음한 음성을 외부 AI(Google Gemini)로 보낸다. 무료 키로 보낸 음성은 Google 이 제품 개선에 쓰고 사람이 들을 수 있다.

## 후보

1. 동의 없이 개인정보처리방침에만 적는다
2. iPhone 에서만 동의 화면을 둔다
3. 두 플랫폼 모두 동의 화면을 두고 마이크 권한 요청보다 먼저 묻는다

## 결정

두 플랫폼 모두 동의 화면(S2)을 둔다.

- 동의 전에는 어떤 녹음도 전송하지 않는다
- 동의는 버튼을 눌러야 성립한다. 뒤로가기나 홈으로 나가는 것은 동의가 아니다
- 동의 화면은 마이크 권한 요청보다 먼저 나온다
- 18세 이상, 무료 등급 제한 지역 안내를 함께 둔다
- 설정에서 철회하면 대기 중인 전송도 멈추고 다음 실행 때 동의 화면으로 간다

## 이유

사용자의 목소리를 외부 AI 로 보내는 앱이라 사용자가 알고 고를 수 있어야 한다. 플랫폼마다 다르게 두면 한쪽 사용자만 모른 채 보낸다. 마이크 권한보다 먼저 물어야 사용자가 "무엇에 쓰이는지"를 알고 권한을 준다.

## 결과

첫 실행에 화면이 하나 늘어난다. 동의 상태가 전송 대기열의 조건이 되어 대기열 코드가 동의를 확인한다.
