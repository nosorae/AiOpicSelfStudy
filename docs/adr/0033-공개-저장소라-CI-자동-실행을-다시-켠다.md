# 0033. 공개 저장소라 GitHub CI 자동 실행을 다시 켠다

- 상태: 채택
- 날짜: 2026-10-11
- 대체: 0026

## 배경

0026 은 Actions 무료 시간을 다 써서 자동 실행을 껐다. 그 뒤 저장소를 공개로 바꿨다. 공개 저장소는 GitHub 표준 러너(macOS 포함)를 시간 제한 없이 무료로 쓴다.

## 결정

`ci.yml` 이 main 푸시, PR, 수동 실행에서 돈다. pre-push 훅과 병합 전 로컬 `./gradlew check` 는 그대로 둔다. CI 는 로컬과 다른 운영체제에서만 드러나는 차이를 잡는 두 번째 검사다.

## 결과

- Linux 잡은 시뮬레이터 부팅과 스크린샷 비교를 빼고 돈다. 기준 이미지를 macOS 에서 찍어 글꼴 렌더링이 어긋나므로 비교(`verifyRoborazziAndroidHostTest`)는 macOS 잡에서 한다(#208).
