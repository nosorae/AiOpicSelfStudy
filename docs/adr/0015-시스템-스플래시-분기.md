# 0015. 시작 분기는 시스템 스플래시를 잡아 둔 채 한다

- 상태: 채택
- 날짜: 2026-10-09

## 배경

앱을 켜면 키와 동의 상태에 따라 키 입력, 동의, 홈 중 한 곳으로 가야 한다.

## 후보

1. 앱이 스플래시 화면을 따로 그리고 거기서 분기한다
2. 시스템 스플래시(Android SplashScreen API, iOS 실행 화면)를 잡아 둔 채 저장된 상태만 읽고 분기한다

## 결정

그리는 스플래시 화면을 두지 않는다. Android 는 `setKeepOnScreenCondition` 으로, iOS 는 실행 화면이 떠 있는 동안 저장된 키와 동의 상태만 읽어 갈 곳을 정한다. 키 확인 요청은 여기서 보내지 않는다.

## 이유

Android 12 이상은 시스템 스플래시가 늘 뜨므로 직접 그린 스플래시가 있으면 두 번 뜬다. 저장된 값만 읽으면 네트워크 없이 바로 끝나 스플래시를 오래 잡지 않는다.

## 결과

분기 로직이 화면이 아니라 시작 코드에 있어 테스트는 분기 함수를 따로 떼어 한다.
