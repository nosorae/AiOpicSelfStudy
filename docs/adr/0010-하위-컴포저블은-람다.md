# 0010. onIntent 는 화면 최상위만, 하위 컴포저블은 람다

- 상태: 채택
- 날짜: 2026-10-09

## 배경

상태 없는 화면 안의 작은 컴포저블(버튼 묶음, 카드)에 사용자 동작을 어떻게 넘길지 정해야 한다.

## 후보

1. 모든 컴포저블에 `onIntent: (XxxIntent) -> Unit` 를 넘긴다
2. 화면 최상위만 `onIntent` 를 받고 하위에는 이벤트별 람다를 넘긴다

## 결정

화면 최상위 컴포저블(`XxxScreen`)만 `onIntent` 를 받는다. 하위 컴포저블에는 `onReplayClicked: () -> Unit` 같은 이벤트별 람다를 넘긴다.

## 이유

하위 컴포저블이 특정 화면의 Intent 타입을 모르니 다른 화면에서 다시 쓸 수 있다. 시그니처만 보고 그 컴포저블이 무슨 동작을 내는지 안다. 미리보기에서도 빈 람다만 넘기면 된다.

## 결과

최상위에서 람다를 Intent 로 잇는 줄이 생긴다.
