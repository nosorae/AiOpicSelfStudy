# 0013. 녹음은 조각 파일로 저장하고 이어 녹음한다

- 상태: 채택
- 날짜: 2026-10-09

## 배경

답하는 도중 앱이 죽거나 전화가 오면 녹음이 사라질 수 있다. 2분 가까운 답변을 통째로 잃으면 그 문항을 다시 볼 수 없다.

## 후보

1. 답변 하나를 파일 하나로 끝날 때 저장한다
2. 몇 초 단위 조각 파일로 바로 쓰고, 다시 켜면 같은 문항에서 새 조각으로 이어 녹음한다

## 결정

몇 초 단위 조각 파일로 바로 쓴다.

- 앱이 죽으면 쓰던 조각 하나만 잃는다
- 다시 켜면 같은 문항에서 이어 녹음한다. 그 문항에서 다시 듣기를 안 썼으면 한 번 들을 수 있다
- 전화나 Siri 가 끼어들면 그 구간을 표시하고, 끝나면 새 조각으로 다시 녹음한다
- 끊긴 지점은 분석 요청에 표시해 말 멈춤으로 세지 않게 한다
- 전송 직전 조각을 한 파일로 합쳐 요청에 넣는다

## 이유

이어 보기(0012)가 문항 단위로 복원돼도 녹음이 사라지면 의미가 없다. 조각으로 쓰면 잃는 양이 몇 초로 줄고, 플랫폼마다 다른 중단 처리(전화, Siri, 앱 종료)를 "새 조각 시작" 하나로 맞춘다.

## 결과

조각을 합치는 코드와 조각 목록 관리가 생긴다. 녹음 폴더는 자동 백업에서 뺀다.
