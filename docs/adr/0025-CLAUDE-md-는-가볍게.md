# 0025. CLAUDE.md 는 매번 지킬 것만 두고 나머지는 경로 규칙과 스킬로 옮긴다

- 상태: 채택
- 날짜: 2026-10-09
- 대체: 0017 의 "모든 규칙을 CLAUDE.md 에 쓴다"

## 배경

0017 로 규칙을 CLAUDE.md 하나에 모았더니 150줄을 넘었다. CLAUDE.md 는 모든 세션의 첫 컨텍스트에 통째로 들어간다. 문서만 고치는 세션에도 모듈 표, 플러그인 id 표, PR 절차, 스킬 표가 따라 들어가서, 정작 매번 지켜야 할 규칙이 그 사이에 묻힌다.

## 후보

1. 지금처럼 CLAUDE.md 하나에 둔다
2. 주제별 문서로 나누고 CLAUDE.md 에서 `@` 로 불러온다
3. CLAUDE.md 에는 매번 지킬 것과 찾아갈 곳만 두고, 나머지는 필요할 때만 읽히는 곳으로 옮긴다

## 결정

3을 고른다.

- CLAUDE.md: 앱 한 문단, 핵심 명령, 꼭 지킬 것, 어디를 보나. 50줄을 넘기지 않는다
- 모듈 층과 빌드 플러그인: `.claude/rules/build.md`. 빌드 파일을 열 때만 읽힌다
- 이슈, PR, 안쪽 루프, 민감 정보 처리, 그 밖의 명령: `node-workflow` 스킬. 노드를 시작할 때 부른다
- 스킬 목록 표는 지운다. 각 스킬의 description 이 언제 쓰는지 말한다

## 이유

`@` 로 불러오면 결국 매 세션에 다 들어가서 2는 1과 같다. 경로 규칙과 스킬은 그 일을 할 때만 컨텍스트에 들어간다. CLAUDE.md 가 짧으면 공개 저장소를 처음 여는 사람도 무엇을 지켜야 하는지 한 화면에 본다.

## 결과

규칙을 더할 때 "매 세션 지켜야 하나"를 먼저 묻는다. 아니면 경로 규칙이나 스킬에 넣는다. 그래프 h2 노드의 완료 명령(200줄 이하)은 그대로 둔다.
