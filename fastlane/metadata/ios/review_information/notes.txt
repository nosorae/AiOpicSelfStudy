이 앱은 서버와 계정이 없습니다. 사용자가 자기 Google Gemini API 키를 넣고, 앱이 그 키로 Gemini 에 답변 녹음을 보내 분석합니다.

심사용 Gemini API 키: {{REVIEW_GEMINI_KEY}}

확인 순서
1. 첫 화면에서 위 키를 붙여 넣고 저장합니다. 앱이 Gemini 에 짧은 요청을 보내 키를 확인합니다
2. 음성 전송 동의 화면에서 동의를 누릅니다. 동의 전에는 어떤 녹음도 보내지 않습니다
3. 모의고사 탭에서 시작을 누르고 서베이와 난이도를 고릅니다. 장비 점검에서 마이크 권한을 묻습니다
4. 문항에서 Play 를 누르면 기기 음성으로 질문을 읽고, 끝나면 녹음이 시작됩니다. Next 는 녹음 10초 뒤에 켜집니다
5. Next 를 누르면 그 답변을 Gemini 로 보내 분석합니다. 연습 탭의 Play 로 한 문항만 풀면 피드백을 바로 볼 수 있습니다

마이크는 사용자가 연 문항 화면에서 답변을 녹음할 때만 씁니다. 답하는 도중 화면이 꺼져도 답이 끊기지 않게 백그라운드 오디오로 녹음을 잇습니다.
알림 권한은 첫 분석을 시작할 때 한 번 묻고, "리포트가 준비됐어요"와 분석 실패 알림에만 씁니다. 광고나 홍보 알림은 없습니다.
